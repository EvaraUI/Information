# Privacy Policy
1. Information We Collect
The only information we collect is the Roblox Private Server link that you provide when starting a session.

2. How We Use Your Information
The link is used solely to run the session command and allow members to join the server.

We do not use this information for any other purpose.

3. Data Retention
The link is deleted from our database immediately after the command successfully runs.

The session message posted in Discord will remain visible unless manually deleted by moderators or admins.

4. Data Sharing
We do not share your Roblox Private Server link with any third parties.

The link is only visible in the Discord message created for the session.

5. Security
We take reasonable steps to ensure that the link is only stored temporarily and removed after use.

However, please remember that the Discord message itself is public to server members and not automatically deleted.

6. Changes
We may update this Privacy Policy from time to time. Continued use of the service means you accept the updated terms.
